《这个神坛不太灵》表情包放置说明

路径:
  assets/stickers/

命名规则:
  与 assets/signs/ 里的签图同名。
  例如签图是 assets/signs/anside_01.png, 对应表情包就是 assets/stickers/anside_01.png。

当前需要的 10 个文件:
  anside_01.png  求上岸神 / 一岸登成
  anside_02.png  求上岸神 / 贵人相助
  anside_03.png  求上岸神 / 岸就在那
  anside_04.png  求上岸神 / 假装在学
  anside_05.png  求上岸神 / 再睡五分
  toufa_01.png   不掉头发神 / 发如韭盛
  toufa_02.png   不掉头发神 / 新芽初生
  toufa_03.png   不掉头发神 / 发际拉锯
  toufa_04.png   不掉头发神 / 偏方千条
  toufa_05.png   不掉头发神 / 帽子真好

代码行为:
  点击「保存表情包 / 签图」后, 神签卡读取 assets/signs/{id}.png。
  表情包 tab 读取 assets/stickers/{id}.png。
  下载到本地时, 文件名会自动变成 {id}_emoji.png, 例如 anside_01_emoji.png。
